**Laboratory Activity: Recursion**

Brief Description:

This program calculates the Greatest Common Divisor (GCD) of two non-negative integers using the recursive Euclidean algorithm.
The program also displays the recursive calls so that the execution of the recursion can be observed.

Programming Language : Java

How to Compile and Run

1. Install Java Development Kit (JDK).
2. Save the source code as RecursiveGCD.java.
3. Open a terminal or command prompt in the folder containing the file.
4. Compile the program:
   javac RecursiveGCD.java
5. Run the program:
   java RecursiveGCD
6. Enter two non-negative integers when requested.

**Sample Input**

Enter first number: 48

Enter second number: 18

**Sample Output**

gcd(48, 18)

a % b = 12

gcd(18, 12)

a % b = 6

gcd(12, 6)

a % b = 0

gcd(6, 0)

GCD = 6
